## 副控 ESP32 电源控制

主控通过 **STM32 PB1（`ESP_EN`）** 控制副控电源：
- PB1 = HIGH → ESP 上电
- PB1 = LOW  → ESP 断电

UART 通信线（任何方案都必接）：

| ESP32-C3        | STM32L431       | 说明                |
| --------------- | --------------- | ------------------- |
| GPIO4 (TX1)     | PA3 (USART2_RX) | 必接                |
| GPIO5 (RX1)     | PA2 (USART2_TX) | 可选，当前固件未用  |
| GND             | GND             | 必接，共地          |

## 当前方案（无元件，纯软件 deep sleep）

> 手头没有 P-MOSFET 也没有合适电阻，**先靠 ESP32-C3 的 deep sleep 模拟"断电"**，今天即可跑通完整业务逻辑。

### 接线（极简）

- ESP32 模组 VCC 直接接 VBAT（或 3V3，看模组）
- ESP32 GND ↔ STM32 GND 共地
- UART 三根线按上表接
- **PB1 悬空不接**，也可以接 LED 观察主控的"上电意图"
- 1µF 电容可选：跨在 ESP 模组 VCC↔GND 之间（越靠近模组越好），抑制联网瞬时电压跌落

### 工作原理

副控 [esp32-c3-mini.ino](esp32-c3-mini/esp32-c3-mini.ino) 已开启**定时唤醒**：
- 上电 → 联网 → NTP 校时 → 发 `T:` 帧
- 拉天气 → 发 `W:` 帧
- 发 `D\n` 通知主控本轮完成
- `esp_sleep_enable_timer_wakeup(3h)` + `esp_deep_sleep_start()` 睡 3 小时
- 3 小时后**自己醒来**重复上述流程

### 功耗

- Deep sleep 静态电流 ≈ 5 µA × 24h ≈ 0.12 mAh/天
- 联网窗口 ≈ 30s/次 × 8 次/天 × 平均 80mA ≈ 5.3 mAh/天
- 与真断电方案差距 < 3 mAh/天，对锂电+太阳能项目**测不出区别**

### 局限

- 主控 PB1 的状态机依然在跑，但因为 PB1 没接东西，**toggling 不会真断电**。所有功能都靠副控自己的 deep sleep 时序维持
- 屏幕上"ESP 在线"图标只在副控醒着的 30s 窗口内点亮，符合预期

顺手再买一袋常用电阻 **1k / 4.7k / 10k / 100k 各 10 颗**，几块钱够用很久。

### 接线图

```
        VBAT (锂电+)
          │
          ├────────────┐
          │            │ S
       100kΩ         ┌─┴─┐
          │     ┌────┤   │  P-MOSFET (AO3401)
          ├─────┘    └─┬─┘
        Gate           │ D ─┬────► ESP32 模组 VCC
                            │
                          [1µF]   ← 电源去耦，越靠近模组越好
                            │
                           GND

   STM32 PB1 ── 1kΩ ──┐ B
                     ┌─┴─┐
                     │S8050│ NPN
                     └─┬─┘
                     E │
                       └────── GND (与 STM32、ESP32 共地)

   STM32 3V3 ── 100kΩ ── STM32 PA3 (USART2_RX)   ← 防止 ESP 断电时 RX 浮空
```

**开关逻辑**：
- PB1 = HIGH → S8050 饱和 → P-MOS Gate 被拉到 GND → P-MOS 导通 → ESP 上电
- PB1 = LOW  → S8050 截止 → Gate 被 100k 上拉到 VBAT → P-MOS 截止 → ESP 真·断电

### S8050（NPN）封装与引脚

**TO-92 封装**（圆头一面朝自己，平面/印字面朝向自己，3 脚朝下）：

```
        ┌───┐
        │   │
        │ S │ ← 印字面朝自己
        │8050│
        └─┬─┘
          │
        E B C   ← 从左到右：发射极 / 基极 / 集电极
       (1)(2)(3)
```

**SOT-23 贴片封装**：脚 1 = B、脚 2 = E、脚 3 = C

| S8050 引脚 | 接到                          |
| ---------- | ----------------------------- |
| B (基极)   | STM32 PB1 → 串 1kΩ → 这里      |
| C (集电极) | P-MOSFET 的 Gate              |
| E (发射极) | GND（与 STM32、ESP32 共地）   |

> ⚠️ 别把 E 和 C 接反！S8050 是 NPN，**E 必须接 GND**，否则不工作甚至烧管。

### 从"软件 deep sleep"切到方案 A 的步骤

1. 按上图焊接 P-MOS、S8050、3 个电阻、1µF 电容
2. PB1 接到 S8050 的 B（经 1kΩ 限流）
3. 把 [esp32-c3-mini.ino](esp32-c3-mini/esp32-c3-mini.ino) 里这行删掉或注释：
   ```cpp
   esp_sleep_enable_timer_wakeup(3ULL * 3600ULL * 1000000ULL);  /* 3h */
   ```
   让 ESP 进入"永远睡，靠主控切电唤醒"模式
4. 主控代码不动，rebuild 烧录 ESP
5. 测：上电后 ESP 跑一次会话发 `D\n`，主控应立即把 PB1 拉低断电；3 小时后主控自动重新上电
