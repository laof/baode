## SHT30 温湿度（I2C）

| STM32 | SHT30 模块 | 说明 |
|---|---|---|
| 3V3 | VCC / VIN | 电源 |
| GND | GND | 共地 |
| B6 | SCL | I2C1_SCL |
| B7 | SDA | I2C1_SDA |
| GND | ADDR | 接 GND → 7-bit 地址 0x44；接 VDD → 0x45 |


模块板通常已带 10kΩ 上拉；裸芯片需在 SDA/SCL 各加 4.7~10kΩ 上拉到 3V3。


## ESP32-C3-Pro Mini 副控（UART 时间桥）

ESP32 联 Wi-Fi → NTP 同步 → 每 10s 通过 UART 发送 `T:YYYY-MM-DD HH:MM:SS\n` 给 STM32。

**物理接线（在原有基础上加 3 根）**

| ESP32-C3 | STM32 (USART2) | 说明 |
|---|---|---|
| **GPIO4** (Serial1 TX) | **PA3** (USART2_RX) | 时间数据 ESP→STM（必接） |
| **GPIO5** (Serial1 RX) | **PA2** (USART2_TX) | 双向必接（主对副） |
| **GND** | **GND** | 共地（必接） |

> **供电说明**：
> - 推荐**两块板各自插 USB 独立供电**，此时**只连 GND**，不要连 VCC。
> - 如果只想给一块板供电、由它带另一块：再加一根 **3V3 ↔ 3V3**（例如 STM32 调试器供电，把 STM32 的 3V3 接到 ESP32 的 3V3 引脚）。
> - **严禁** 5V ↔ 3V3 互连，会烧板。GND 任何情况下都必须连通，否则 UART 没有参考电平。

波特率 **115200 8N1**。

> ESP32-C3 默认 `Serial` 走 USB-CDC，调试日志看 USB；与 STM32 通讯走 `Serial1` (GPIO4/5)，互不冲突。
> Wi-Fi SSID/密码 + 天气城市放在 `esp32-c3-mini/secrets.h`（已被 `.gitignore` 排除），首次使用复制 `secrets.h.example` 为 `secrets.h` 并填入。


## 串口协议（双向，行式 ASCII，`\n` 结束）

| 方向 | 帧 | 长度 | 含义 / 频率 |
|---|---|---|---|
| STM32 → ESP | `P\n` | 2B | ping，每 5s 一次 |
| ESP → STM32 | `S:W\n` / `S:N\n` | 3B | Wi-Fi 已连 / 未连，收到 `P` 立即回 |
| ESP → STM32 | `T:YYYY-MM-DD HH:MM:SS\n` | 21B | 时间，每 10s 一次 |
| ESP → STM32 | `W:<code>,<temp>\n` | 5–8B | 天气，每 1h 一次。`code`：0=晴 1=多云 2=阴/雾 3=雨 4=雪；`temp`：摄氏度整数，可负，例 `W:0,-3\n` |

STM32 把“最近一次收到任意帧”作为副控心跳，超过 **12s** 没收到就认为副控离线，右上角 ESP/WiFi 图标消失。


## 屏幕布局， 图标和文字要vertical-align middle

```
┌──────────────────────────────┐
│                    [ESP][WiFi]│  cy=16   顶部：副控芯片 + WiFi，共享中线
│                              │
│ [水滴 3x]   11.1C   [!]      │  cy=56   露点（最看重，size=5），图标/文字垂直居中
│                              │
│ [天气 2x]   18C              │  cy=132  天气（2x 图标 + size=4 温度），图标/文字垂直居中
│                              │
│  T:25.6C                     │  y=200   室内温度（size=4）
│  H:58.7%                     │  y=250   室内湿度（size=4）
│                              │
│ 12-06 14:45      [月] 4-7    │  cy=380  底部左：月日时分(size=2) ；底部右：月亮图标 + 农历 MM-DD(size=2)
└──────────────────────────────┘
```

字号梯度：露点 5 → 天气/室内 4 → 底部公历/农历 2，整体协调，没有从超大跳到很小的突兀感。**所有「图标 + 同行文字」按中心垂直对齐**（相当于 CSS `vertical-align: middle`），图标和文字之间留 24px 横向间距，避免拥挤。

- 顶部：副控芯片图标 (26×22) + **WiFi 图标** (22×16，3 道收紧的同心弧 + 底部圆点)。仅在副控在线且 WiFi 已连时显示，两者共享中线 `cy=16`，右对齐到屏宽 300、右边距 4px。
  - **WiFi 已连**：经典 3 道弧 + 底部圆点的 WiFi 图标
  - **WiFi 失联 / 副控离线**：不显示
- 露点行（**最看重，放第二位**）：3x 大水滴 + **size=5 露点温度**，露点 < 8°C 时右侧多一个粗 `!` 提示"该开加湿器了"。露点用 Magnus 近似算出，比只看 RH 更能反映"皮肤干不干"。
- 天气行（紧贴露点下面）：**天气图标 56×44**（2x）+ **室外温度 size=4**。拿到天气前整行不画。天气图标 5 种：晴 / 多云 / 阴 / 雨 / 雪。
- 室内温湿度：SHT30 实测，size=4。
- 底部行（**左 + 右两块**，共享中线 `cy=380`）：
  - **左**：`MM-DD HH:MM`（去年份、去秒，例 `12-06 14:45`），size=2。墙钟越安静越好，秒跳动会分散注意力。
  - **右**：**月亮图标 12×14 + 农历 `MM-DD`**（size=2），右对齐到屏宽 300、右边距 4px。公历与农历同字号以保持视觉一致。闰月在月份前加 `*`，例 `*5-15`。农历换算覆盖 **1900–2049**（内置 150 年数据表，约 600B Flash）。

**露点显示规则**

> 下表里的 `(水滴)` 和 `(!)` 都不是文字，而是程序用像素画的**小图标**。屏上看到的是图形，不是字母。

| 露点 | 屏上实际显示 | 含义 |
|---|---|---|
| ≥ 8.0°C | `(水滴)  11.1C` | 舒服，不用动 |
| < 8.0°C | `(水滴)  5.3C  (!)` | 偏干，建议开加湿器 |
| 没数据 (RH=0) | 整行不画 | 传感器还没读到 |

- `(水滴)`：42×48 像素的实心水滴图形（3x 放大）。
- 中间数字：露点温度，size=5。
- `(!)`：5 像素宽的粗感叹号（竖条 + 下点），凸显加湿提醒。


## 天气功能（wttr.in）

ESP32 每小时拉一次 `http://wttr.in/<城市>?format=%C|%t&m`，把返回的文本（如 `Partly cloudy|+18°C`）归类成 5 个图标之一，连同温度通过 `W:` 帧发给 STM32。

- 城市配置在 `esp32-c3-mini/secrets.h`：`#define WEATHER_CITY "Beijing"`。可用拼音 / 英文 / IATA 机场代码。
- 无需 API Key。
- 拉失败（超时、HTTP 非 200、wttr.in 偶尔不稳）会在 1 分钟后重试，不影响时间/Wi-Fi 状态上报。
