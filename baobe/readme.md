## SHT30 温湿度（I2C）

| STM32 | SHT30 模块 | 说明 |
|---|---|---|
| 3V3 | VCC / VIN | 电源 |
| GND | GND | 共地 |
| B6 | SCL | I2C1_SCL |
| B7 | SDA | I2C1_SDA |
| GND | ADDR | 接 GND → 7-bit 地址 0x44；接 VDD → 0x45 |


模块板通常已带 10kΩ 上拉；裸芯片需在 SDA/SCL 各加 4.7~10kΩ 上拉到 3V3。


## ESP32-C3-Pro Mini 副控（UART 时间桥）

ESP32 联 Wi-Fi → NTP 同步 → 每 10s 通过 UART 发送 `T:YYYY-MM-DD HH:MM:SS\n` 给 STM32。

**物理接线（在原有基础上加 3 根）**

| ESP32-C3 | STM32 (USART2) | 说明 |
|---|---|---|
| **GPIO4** (Serial1 TX) | **PA3** (USART2_RX) | 时间数据 ESP→STM（必接） |
| **GPIO5** (Serial1 RX) | **PA2** (USART2_TX) | 双向必接（主对副） |
| **GND** | **GND** | 共地（必接） |

> **供电说明**：
> - 推荐**两块板各自插 USB 独立供电**，此时**只连 GND**，不要连 VCC。
> - 如果只想给一块板供电、由它带另一块：再加一根 **3V3 ↔ 3V3**（例如 STM32 调试器供电，把 STM32 的 3V3 接到 ESP32 的 3V3 引脚）。
> - **严禁** 5V ↔ 3V3 互连，会烧板。GND 任何情况下都必须连通，否则 UART 没有参考电平。

波特率 **115200 8N1**。

> ESP32-C3 默认 `Serial` 走 USB-CDC，调试日志看 USB；与 STM32 通讯走 `Serial1` (GPIO4/5)，互不冲突。
> Wi-Fi SSID/密码 + 天气城市放在 `esp32-c3-mini/secrets.h`（已被 `.gitignore` 排除），首次使用复制 `secrets.h.example` 为 `secrets.h` 并填入。


## 串口协议（双向，行式 ASCII，`\n` 结束）

| 方向 | 帧 | 长度 | 含义 / 频率 |
|---|---|---|---|
| STM32 → ESP | `P\n` | 2B | ping，每 5s 一次 |
| ESP → STM32 | `S:W\n` / `S:N\n` | 3B | Wi-Fi 已连 / 未连，收到 `P` 立即回 |
| ESP → STM32 | `T:YYYY-MM-DD HH:MM:SS\n` | 21B | 时间，每 10s 一次 |
| ESP → STM32 | `W:<code>,<temp>\n` | 5–8B | 天气，每 1h 一次。`code`：0=晴 1=多云 2=阴/雾 3=雨 4=雪；`temp`：摄氏度整数，可负，例 `W:0,-3\n` |

STM32 把“最近一次收到任意帧”作为副控心跳，超过 **12s** 没收到就认为副控离线，右上角 ESP/WiFi 图标消失。


## 屏幕布局

```
┌──────────────────────────────┐
│ [天气][18C]        [ESP][WiFi]│  y=2~24   顶部状态栏
│  2026-12-06                  │  y=30
│                              │
│   14:45:01                   │  y=80    大字时钟
│                              │
│  T:25.6C                     │  y=190   室内温度（SHT30）
│  H:58.7%                     │  y=240   室内湿度（SHT30）
│ [滴]11.1C                    │  y=290   露点（算出来），偏干显示 "!"
└──────────────────────────────┘
```

- 左上：天气图标 + 室外温度（拿到天气前不显示）。天气图标 5 种：晴 / 多云 / 阴 / 雨 / 雪。
- 右上：副控芯片图标 + WiFi 图标（副控在线时显示；WiFi 失联时 WiFi 图标右侧多一个粗 `!`）。
- 底部：水滴图标 + **露点温度**。露点 < 8°C 时图标右侧多一个粗 `!`，提示"该开加湿器了"。露点用 Magnus 近似算出，比只看 RH 更能反映"皮肤干不干"。

**露点显示规则**

| 露点 | 屏上表现 | 含义 |
|---|---|---|
| ≥ 8.0°C | `[滴]11.1C` | 舒服，不用动 |
| < 8.0°C | `[滴]5.3C !` | 偏干，建议开加湿器 |
| 没数据 (RH=0) | 整行不画 | 传感器还没读到 |


## 天气功能（wttr.in）

ESP32 每小时拉一次 `http://wttr.in/<城市>?format=%C|%t&m`，把返回的文本（如 `Partly cloudy|+18°C`）归类成 5 个图标之一，连同温度通过 `W:` 帧发给 STM32。

- 城市配置在 `esp32-c3-mini/secrets.h`：`#define WEATHER_CITY "Beijing"`。可用拼音 / 英文 / IATA 机场代码。
- 无需 API Key。
- 拉失败（超时、HTTP 非 200、wttr.in 偶尔不稳）会在 1 分钟后重试，不影响时间/Wi-Fi 状态上报。
